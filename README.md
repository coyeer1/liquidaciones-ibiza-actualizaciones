# Actualizaciones del programa de liquidaciones

Aquí solo se publican las versiones nuevas del **programa** (la carpeta `app`), firmadas.
Ningún dato de trabajadores ni de liquidaciones sale del computador donde está instalado.

- `version.json`: versión vigente, notas, huella SHA-256 del archivo y firma Ed25519.
- `app-<versión>.zip`: el programa.

El programa instalado solo acepta versiones con una firma válida.
